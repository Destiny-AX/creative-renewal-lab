# 创意续命实验台 · AI 驱动的广告素材疲劳诊断与续命平台

> 面向信息流广告创意疲劳场景的产品设计与交互原型

[![GitHub release](https://img.shields.io/github/v/release/Destiny-AX/creative-renewal-lab)](https://github.com/Destiny-AX/creative-renewal-lab/releases)

---

## 项目简介

信息流广告素材的生命周期正在急剧缩短：一条爆款素材往往在投放 3-7 天后 CTR 便开始断崖式下滑。优化师们每天面临的问题是：

- 哪些素材已经疲劳了？靠人工巡检很难及时发现；
- 为什么疲劳？是钩子重复、视觉审美疲劳，还是卖点层级混乱？
- 怎么续命？改文案、换封面、调卖点顺序，往往多变量同时改动，导致实验无法归因；
- 改完后合规吗？功效宣称、对比表达容易触发平台审核。

**创意续命实验台** 是一款面向上述痛点的 AI 策略产品原型，覆盖「疲劳诊断 → 智能续命 → 实验复盘」完整闭环，并以「单变量实验」原则确保每一次续命都可归因、可验证、可沉淀。

---

## 产品价值主张

**发现疲劳 → AI 归因 → 单变量续命 → 合规预审 → 实验复盘 → 知识沉淀**

目标用户：品牌投放团队、广告代理商优化师、内容运营。

核心价值：
- **早识别**：基于 CTR 衰减、收藏率衰减、曝光频次、评论信号综合计算疲劳指数；
- **归因准**：AI 分析素材各要素，定位主衰退变量（钩子 / 视觉 / 卖点 / 合规）；
- **续命快**：围绕主变量自动生成 3 组单变量变体，保持其他要素不变；
- **风险低**：实验前自动预审合规风险，对高风险表达给出改写建议；
- **能沉淀**：实验结果自动写回知识库，形成可复用的创意策略。

## 三阶段工作流

### 阶段一：疲劳诊断中心

- 按行业、品类、风险等级筛选素材；
- 顶部统计卡实时展示 CTR 衰减、疲劳指数、推荐主变量；
- AI 归因面板以时间线方式呈现衰退原因；
- 对高疲劳素材提供「一键续命」入口。

### 阶段二：智能续命工作台

- 根据 AI 归因推荐本次实验主变量；
- 自动生成 3 组单变量变体（如只改钩子、只换封面、只调卖点层级）；
- 提供手机预览，直观对比原版与变体；
- 合规预审卡片展示各变体风险等级与改写记录；
- 一键启动实验，素材级状态管理支持并行追踪多个实验。

### 阶段三：复盘看板

- 实验结果对比（对照组 vs 变体组 CTR/CVR）；
- 业务闭环：放量决策、预算分配建议；
- 学习闭环：AI 自动提炼可复用创意策略并写入知识库；
- 合规规则库自动记录新发现的风险模式。

## AI 产品设计思路

### AI 在哪里介入

| 环节 | AI 能力 | 人的决策 |
|---|---|---|
| 疲劳诊断 | 综合多指标计算疲劳指数，识别异常信号 | 确认是否进入续命流程 |
| 归因分析 | 基于素材要素（钩子、视觉、卖点、合规）给出衰退原因假设 | 审核归因结论，补充业务背景 |
| 变体生成 | 围绕主变量生成 3 组候选文案/结构 | 选择最终实验方案 |
| 合规预审 | 识别功效宣称、夸张对比等风险并改写 | 终审是否上线 |
| 复盘沉淀 | 从实验结果中抽取策略模式 | 决定是否写入知识库 |

### 设计原则

1. **单变量实验**：一次只改一个要素，确保结果可归因；
2. **人在回路**：AI 提供候选和假设，关键决策由人确认；
3. **透明可解释**：AI 归因给出具体原因和时间线，而非黑盒分数；
4. **渐进式智能**：从规则 + 模板起步，逐步接入 LLM/RAG。

## 策略产品设计思路

### 疲劳指数计算

综合以下信号：
- CTR 衰减率（最近 7 天 vs 前 7 天）
- 收藏率衰减率
- 人均曝光频次
- 评论中的负面/重复信号比例

输出 0-100 的疲劳指数，并划分：
- 0-59：健康
- 60-79：中风险，持续观察
- 80-100：高风险，建议续命

### 主变量推荐规则

| 疲劳信号 | 推荐主变量 |
|---|---|
| 钩子文案重复、CTR 快速下滑 | 钩子表达 |
| 封面图构图单一、点击意愿下降 | 视觉构图 |
| 信息密度高、收藏率下滑 | 卖点层级 |
| 评论质疑功效/对比真实性 | 合规优化 |

### 实验评估指标

- 核心指标：CTR、CVR、收藏率
- 辅助指标：CPM、曝光频次、评论情绪
- 通过门槛：变体组 CTR 较对照组提升 ≥10% 且持续 24h 以上
